# AGENTS

This repository is intended for lightweight agent-assisted development.

## Expectations
- Make the smallest change that satisfies the request.
- Keep the diff easy to review and explain.
- Preserve existing structure and conventions unless a change is explicitly requested.
- Document meaningful changes in the relevant README or instruction files.
- Verify the result with the available checks or validation steps.

## Notes
- If the task is unclear, clarify the intended outcome before proceeding.
- Avoid adding dependencies or unrelated files when a simpler solution exists.
