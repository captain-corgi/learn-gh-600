# Corgi Mate — Family App UI Kit

A family-assistant app shell: today view, task cards, quick actions, and calm domestic copy.

Open `index.html` in a browser. Requires network for React CDN.

## Screens

- **Today** — done + upcoming tasks with category pills and due times
- **Tasks** — full task list
- **Calendar** — placeholder for shared family calendar
- **Family** — household summary
