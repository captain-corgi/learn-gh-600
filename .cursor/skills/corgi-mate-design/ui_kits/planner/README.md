# Corgi Mate — Household Planner UI Kit

A shared household planner site: events, chore rotation, meal plan, and family member grid.

Open `index.html` in a browser. Requires network for React CDN.

## Sections

- **Overview hero** — "Your household, organized" with calendar pose
- **Events** — upcoming pickups and appointments
- **Chores** — rotation cards by family member
- **Meals** — weekly dinner plan
- **Family** — member grid including Corgi Mate assistant
